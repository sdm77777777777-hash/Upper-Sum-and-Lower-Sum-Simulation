What is happening here?

The Darboux definition of the Riemann integral says:

A function is integrable if and only if the Lower Sum and Upper Sum can be made arbitrarily close by refining the partition.

  • Lower Sum (L): Uses the infimum (greatest lower bound) in each slice. Always L ≤ True Area.
  • Upper Sum (U): Uses the supremum (least upper bound) in each slice. Always U ≥ True Area.
  • As n → ∞, if U − L → 0, then the function is Riemann integrable and the common limit is the integral.
